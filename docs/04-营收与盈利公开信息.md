## 3. 盈利状况：能确定的和不能确定的

**能确定的（基于官方定性表述）：**
1. **Copilot 曾经压低毛利率。** GitHub 官方在计费改革博文里承认，旧的 premium request 模式下“GitHub 吸收了大部分不断上升的推理成本”，“现有模式已不可持续”【官方，2026-04】。CFO 也确认 Copilot 用量拖累了分部毛利率【官方，FY26 Q4】。
2. **按量计费改善了单位经济性。** CFO 称改价后“毛利率在季度内改善”【官方】。
3. **安全模块是高增长的利润池。** GHAS 收入同比增长 50% 以上【官方，FY27 Q1】。

**不能确定的：**
- GitHub 整体的营收、经营利润和净利润绝对值（未披露）。
- Copilot 收入的美元绝对值（FourWeekMBA 也明确指出电话会没给美元数）。
- 2024 年之后 GitHub 的 run-rate（官方没有更新）。

## 4. 本文推断【推断，非事实，仅供参考】

| 问题 | 推断 | 依据与不确定性 |
|---|---|---|
| GitHub 2026 年营收规模 | **大概率明显高于 2024 年的 20 亿美元 run-rate**，但给不出可靠区间 | 用户从 2024 年约 1.5 亿（按 Octoverse 2025 的“1.8 亿+”倒推，待核实）增至 2.25 亿；Copilot 用户从 2,600 万增至 5,000 万；FY26 Q4 Copilot 收入环比加速 60% 以上；GHAS 同比增长 50% 以上。但席位平均价、折扣和 credits 消耗量都未知，任何具体数字都是猜 |
| 盈利性 | 平台订阅、Actions、安全业务大概率是高毛利；Copilot 在 2025 至 2026-05 期间很可能毛利很薄甚至为负；2026-06 之后有所修复 | 官方“不可持续”“吸收成本”“毛利率受拖累后改善”的表述；Azure 迁移和扩容（400 万核等）推高成本 |
| 收购回报 | 从战略价值看，收购已经“赚回来”：Copilot 单项业务就超过了收购时的整个 GitHub | 官方表述；但财务 IRR 无法计算 |

## 5. 结论

- **公开信息只能证明三件事**：规模在加速（用户、活动量）；AI 用量带来的收入在加速（60% 以上、翻倍、75% 以上）；AI 曾压低毛利率，按量计费后在修复。
- **“GitHub 赚多少钱”没有官方答案。** 任何声称精确利润的说法都应视为不可信。
