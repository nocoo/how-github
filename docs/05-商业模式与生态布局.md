# 05 · 商业模式与生态布局

> 更新：2026-11-09（北京时间）｜ 标注规则同 [README](README.md)

## 1. 收入结构（定性拆解）

GitHub 不披露收入构成。以下是按收费面整理的结构【推断，基于 03 的定价】：

| 收入线 | 计费方式 | 主要客户 | 增长驱动 | 毛利特征（推断） |
|---|---|---|---|---|
| 平台席位（Team/Enterprise Cloud/Server） | 按用户/月 | 企业、团队 | 企业上云、合规（EMU、数据驻留、FedRAMP） | 高 |
| GitHub Copilot | 席位 + AI Credits 按量 | 个人、企业 | 代理化编程、多模型 | 依赖模型推理成本，2026-06 后改善 |
| Actions / Codespaces / sandbox | 按分钟、核时 | 私有仓库用户 | CI 量、代理执行 | 中（底层是 Azure 计算） |
| Packages / LFS / 存储 | 按 GB | 私有制品 | 制品规模 | 中高 |
| 安全（Secret Protection / Code Security） | 按活跃提交者 + AI Credits | 企业 | 供应链安全、AI 代码风险 | 高；官方称同比增长 50% 以上 |
| 支持（Premium） | 合同 | 大企业 | — | 高 |
| 生态（Marketplace、Sponsors） | 分成、手续费 | 开发者 | 网络效应 | 金额小，战略意义大 |

## 2. 商业飞轮

```
免费公开仓库 / 教育 / 开源  →  2.25 亿开发者与代码图谱
        ↓                                ↓
  个人 Copilot（Free→Pro→Max）   企业采购（GHEC + 安全 + Copilot）
        ↓                                ↓
  代理活动量暴涨（40%+ PR 由代理起草）  →  Actions/sandbox/credits 消耗
        ↓
  更多数据（2026-04 起个人档交互数据默认用于训练）→ 模型和路由（Fusion、MAI-Code）改进
```

- **免费层是获客漏斗**：公开仓库、Actions、安全功能对开源免费，学生和教师免费。
- **企业层是现金牛**：Enterprise $21 + 安全 $19/$30 + Copilot。
- **AI 层是增长引擎**：从“卖席位”转向“卖用量”，与 Azure 的消费型收入逻辑一致。

## 4. 开源与开发者生态

- **Sponsors**：个人赞助零手续费，组织赞助最多 6%【官方】。
- **Copilot for OSS**：热门开源维护者可以免费用 Pro【官方】。
- **维护者工具**：2026 年针对 AI 垃圾贡献推出关闭 PR、限制 PR 数量等功能【官方/社区】，算是对生态的补偿。
- **Agent HQ 的开放姿态**：接入 Claude、Codex、Jules、Cognition、xAI 等第三方代理【媒体，InfoQ】。官方的说法是“每个主要编码代理都在 GitHub 上运行”【官方，FY26 Q4】。思路是**把竞争对手变成平台上的租户**。

## 5. 教育与政府

- 学生和教师可以免费使用开发工具与 Copilot Student【官方】。
- Enterprise 支持 FedRAMP Tailored ATO、SOC1/SOC2，数据驻留目前覆盖 EU 和澳洲【官方，pricing】。

## 6. 结论

1. 商业模式正从 **SaaS 席位制**转向 **“席位 + 云计算式用量”混合制**。2026-10 推出的 Copilot access（席位 $0、纯按量）是这个方向最激进的一步。
2. GitHub 最难被复制的资产是**开发者身份 + 代码 + 协作流程（PR/Issue/Actions）的集中地**。代理再多，它们产出的 PR 也大多流回 GitHub，这正是 Agent HQ 敢接入竞品的底气。
3. 风险在于“平台中立性”和“微软利益”之间的张力，见 07、08。
