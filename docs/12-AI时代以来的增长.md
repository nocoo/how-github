# 12 · AI 时代以来 GitHub 的增长

> 更新：2026-11-09（北京时间）｜ 第二期补充 ｜ 标注规则同 [README](README.md)，【X】= X 公开帖子。
> 时间起点：以 **2021-06 Copilot 技术预览 / 2022-11 ChatGPT 发布** 作为“AI 时代”起点，对照 2018 年收购时的基线。
> **口径警告**：Octoverse 每年口径会变（“开发者”= 账户数；“贡献”有时只算公开仓库，有时含私有；统计窗口多为截至当年 9 月的 12 个月）。跨年比较只看量级与方向，不要精算增速。

## 4. 代理化的速度

| 指标 | 数值 | 来源 |
|---|---|---|
| 代理起草的 PR 占比 | 2026-03 **17%** → 2026-09 **40%+** | 【官方】Octoverse 2026 |
| 9 月代理 PR 数 | 1.1 亿 | 【官方】同上 |
| 2025 年 AI 代理 PR | 月均合并 PR 4,300 万中“超过 100 万”由代理撰写 | 【X】@siyaaaamak 转述 Octoverse 2025 https://x.com/siyaaaamak/status/2024394376349208962 |
| Copilot 月活中使用代理功能 | 35%（2025）→ 55%（2026） | 【官方】Octoverse 2026 |
| Copilot cloud agent | 同比 +230% | 【官方】同上 |
| 单仓库代理并发 | 新存储架构内测 5,000 个代理、每秒 7,200 次 push | 【官方】github.blog 2026-11 |

【推断】从 2025 年“百万级代理 PR / 月”到 2026-09“1.1 亿代理 PR / 月”，**一年约百倍**。这条曲线比开发者人数曲线（一年 +25%）陡得多——**GitHub 的增长引擎已经从“人”切换到“代理”**。
