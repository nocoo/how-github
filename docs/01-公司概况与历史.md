## 1. 一句话定位

GitHub 是全球最大的代码托管与软件协作平台，2018 年起归属微软。2026 年官方把自己定位成“面向开发者及其 AI 代理（agents）的端到端软件交付系统”【官方，Universe 2026】。

## 4. 组织与领导层（2026-11）

- **归属**：微软 **CoreAI** 事业群，由 EVP Jay Parikh 领导。Universe 2026 的主旨文章署名就是 Jay Parikh【官方】。
- **GitHub 层面**：CPO Mario Rodriguez（2026-04 计费改革文章署名）【官方】、COO Kyle Daigle【媒体】、CTO Vladimir Fedorov【媒体】。
- **待核实**：2025-08 以后 GitHub 是否任命了新的独立 CEO。本次检索没有发现，媒体当时报道称“不直接替补”。
- **独立性**：媒体报道 GitHub 内部协作工具从 Slack 换成 Teams，领导层向多位微软高管汇报，独立性下降【媒体，WindowsForum 转述 The Verge】。

## 5. 结论

1. GitHub 已经从“微软旗下独立运营的子公司”变成“微软 CoreAI 的一个产品线”，组织、基础设施（Azure）、计费（AI Credits）都在向微软体系收拢。
2. 用户规模还在加速增长：2018 年 2,800 万，2026 年 2.25 亿。驱动力从“开源协作”变成了“AI 代理带来的活动量”。
3. **待核实**：Octoverse 2025 的 1.8 亿开发者口径（本次只看到二手引用）。
