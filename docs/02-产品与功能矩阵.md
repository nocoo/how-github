# 02 · GitHub 产品与功能矩阵

> 更新：2026-11-09（北京时间）｜ 来源：github.com/pricing、github.com/features/copilot/plans、docs.github.com、Universe 2026 博文（均为 2026-11 查询）｜ 标注规则同 [README](README.md)

## 1. 产品地图（按开发生命周期）

| 层 | 产品/功能 | 说明 | 收费方式 |
|---|---|---|---|
| 代码与协作 | Repositories、Pull Requests、Code Review、Issues、Projects、Discussions、Wikis、Pages | 核心协作层，公开和私有仓库都不限数量 | 免费为主；高级规则、代码所有者等功能在 Team 及以上 |
| 规则治理 | Repository rules、Code owners、Required reviewers、Environment protection | 分支保护和合规 | Team/Enterprise |
| CI/CD | **GitHub Actions**（托管/自托管/大型 runner，自定义镜像） | 2026 年日均 1.24 亿次任务 | 按量：每月含一定金额的额度，超出后按分钟计费 |
| 云开发环境 | **Codespaces** | 云端 VS Code/容器开发环境 | 按核时和存储计费 |
| 制品 | **GitHub Packages**、Container Registry、Git LFS | npm/Maven/NuGet/容器等 | 按存储和流量计费；容器镜像暂时免费 |
| 安全 | Dependabot、**Secret Protection**、**Code Security**（CodeQL、Copilot Autofix、安全活动）、SBOM、Artifact attestations | 公开仓库大多免费 | 按活跃提交者订阅，AI 功能另按 AI Credits 计费 |
| AI | **GitHub Copilot**（补全、Chat、Agent mode、云端代理、代码审查、CLI、Copilot app、Spaces、Automations、Fusion 模型路由） | 2026 年已转向“代理优先” | 订阅 + AI Credits 按量计费 |
| 代理平台 | **Agent HQ / mission control**、第三方代理（Claude、Codex 等）、MCP | 在 GitHub 上统一调度多家代理 | 包含在 Copilot 付费档内，按用量消耗 |
| 代理沙箱 | **GitHub sandbox**（隔离、有状态的云环境，支持快照/恢复，运行代理生成的代码） | 2026 年定价页新增项 | 按量计费，与 Actions 共用计算额度【官方，pricing、Actions billing】 |
| 模型 | GitHub Models、Copilot 内多家模型（Anthropic、OpenAI、Google、xAI、Microsoft MAI、Kimi 等） | 2026-09 付费用户用过 47 个模型 | 按 AI Credits |
| 企业 | Enterprise Cloud（含 EMU、数据驻留 EU/澳洲、FedRAMP Tailored）、Enterprise Server（自托管） | 审计、SAML、SCIM | 21 美元/用户/月起 |
| 生态 | Marketplace（Apps/Actions）、GitHub Sponsors、Education（学生/教师）、Copilot for OSS 维护者 | 开发者网络效应 | 分成/手续费，或免费 |

## 3. 平台规模与基础设施（Universe 2026 披露）

- 2026 年以来新增 **400 万 CPU 核、160 PB 高速存储、50 Tb/s 网络容量**【官方】。
- 正在迁往 **Azure 多区域部署**，“预计明年初完成”。2026 年 6 月的可用性报告显示：Central US 单体流量在 Azure 上的占比峰值为 45%，Git 流量占比峰值 43%，没达到 6 月 50% 的目标【官方】。
- 正在重构 Git 存储架构：存算分离、按引用（per-reference）的 quorum、对象存储【官方，github.blog 摘要】。

## 4. 结论

- GitHub 的产品重心已经从“托管 + 协作”转到“AI 代理的工作台和控制台”：Agent HQ、Copilot app、sandbox、Fusion 都围绕“代理产出 PR，人来审查合并”这一闭环设计。
- 收费面在扩大：代码审查、沙箱、安全扫描（AI Scan / agentic autofix）都开始计入 AI Credits 或 Actions 计算额度。
