> 更新：2026-11-09（北京时间）｜ 竞品收入多为第三方追踪或媒体报道，**可信度低于官方**，已逐条标注。｜ 标注规则同 [README](README.md)

| 其他 | Lovable、Replit、Zed、opencode 等 | “vibe coding” 赛道 | 【媒体】 |

**对 GitHub 的含义**【推断】：
- **Copilot 在“最强代理”的心智竞争中不占上风**。市场叙事的主角是 Cursor 和 Claude Code。GitHub 用 5,000 万用户（大量是免费用户、学生、企业分配的席位）证明覆盖面，但没有披露付费用户数和收入。
- **竞品同时也是 GitHub 的客户和租户**：Claude Code、Codex 产出的 PR 照样在 GitHub 上合并，GitHub 从 Actions、审查、安全和平台席位上赚钱。Agent HQ 就是这种“竞合”关系的产品化。
- **地缘与资本格局变化**：Cursor 归属 SpaceX；OpenAI 自研代码托管（见 §3）；Anthropic、OpenAI 都在往“开发平台”方向走。GitHub 的上游模型供应商也正在变成它的竞争对手。

## 2. 代码托管层面的替代者

**判断**【推断】：迁移量在总量中占比很小（GitHub 一年净增数千万开发者），但**象征意义大**。开源核心社区（发行版、语言项目）的流失会削弱 GitHub 的“开源中立”品牌。

## 4. 开源维护者负担与“AI 垃圾”（AI slop）

- 2026-01-27 GitHub 社区讨论正式承认低质量、AI 生成的贡献正在给维护者造成负担【社区，Discussion】。
- tldraw 从 2026-01-15 起自动关闭外部贡献者的 PR【社区】。
- GitHub 的应对：2026-02-13 允许关闭 PR 或只对协作者开放；2026-06-17 限制非写权限用户同时开启的 PR 数；2026-05 “Maintainer Month” 更新了一组降噪工具【官方/社区】。
- 学术研究（MSR 2026，样本 3.3 万+ 个代理 PR）：未被合并的代理 PR 通常改动更大、CI 失败更多，对维护者形成“注意力税”【社区，tesslio 汇总】。
- **悖论**：GitHub 的收入和 KPI（代理 PR 数、credit 消耗）与维护者的负担正相关。平台既卖“生成”，又要帮维护者“过滤”。

## 6. 定价与开发者信任

- 2026-06 改为 token 计费，取消回落到免费模型的兜底，引发不满（TechCrunch 2026-05-30 报道题为 “What a joke…”）【媒体，转引】。改价前还临时收紧了个人档用量，并暂停自助购买 Business 档【官方】。
- 2025-12 宣布对自托管 runner 收费，次日即推迟【官方/社区】，说明价格敏感度很高。
- 平台锁定：Actions、Packages、Copilot、安全、身份（EMU）层层绑定，迁移成本高。这一点既是护城河，也是开发者抱怨的来源。

## 7. AI 时代代码托管的价值在怎么变【推断】

| 维度 | 削弱因素 | 强化因素 |
|---|---|---|
| 代码作为资产 | 代码生成成本趋近于零 | 代码量暴增，需要存储、版本和溯源 |
| 协作 | 代理直接改代码，人类协作减少 | PR 和审查成为人类把关的唯一界面 |
| 发现与社交（star、关注） | AI 检索替代搜索 | 开源依旧是训练和依赖的源头 |
| CI/CD | — | 代理需要大量执行与验证（Actions、sandbox） |
| 安全与合规 | — | AI 代码风险推动 GHAS 增长 50% 以上 |

结论：**托管本身的价值被商品化，“验证、审查、治理、执行”的价值在上升。** GitHub 的战略（code review Max、sandbox、GHAS、Agent HQ 治理）与这个判断一致。

## 8. 小结

1. 最大的外部威胁是 **AI 原生对手抢走开发者入口**（Cursor、Claude Code、Codex），而模型供应商同时也是竞争对手。
2. 最大的内部威胁是 **可靠性**（Azure 迁移叠加代理负载），已经有大客户在评估替代方案。
3. 最大的生态威胁是 **开源信任**（AI 垃圾、训练默认开启、Copilot 被强推）导致核心开源项目边缘化。
