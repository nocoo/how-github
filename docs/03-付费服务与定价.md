## 2. GitHub Copilot

### 2.1 个人档（2026-06-01 起按 AI Credits 计费；1 credit = $0.01）

| 档位 | 月费 | 基础 credits | Flex 额外配额 | 每月总 credits（≈美元） | 要点 |
|---|---|---|---|---|---|
| Free | $0 | 少量额度 | — | 有限 | 每月 2,000 次补全；只能自动选模型；含 Copilot CLI |
| Student | $0（需验证） | 少量额度 | — | 有限 | 不含第三方代理 |
| **Pro** | **$10** | 1,000 | 500 | **1,500（≈$15）** | 补全和 NES 不限量；云端代理、代码审查；可用第三方代理（Claude Code、Codex） |
| **Pro+** | **$39** | 3,900 | 3,100 | **7,000（≈$70）** | 高端模型（含 Opus）；审计日志；可把任务委派给第三方代理 |
| **Max** | **$100** | 10,000 | 10,000 | **20,000（≈$200）** | 新模型和新功能优先；用量最大 |

- Flex 配额“可能随时间变化”【官方】。用完后可以设美元预算继续用，或者切换到更便宜的模型。**不再有自动回落到免费模型的兜底**【官方，UBB 博文】。
- **补全（code completion）和 Next Edit Suggestions 不消耗 credits**，付费档不限量【官方】。
- 2026-06 前的旧体系（只保留给年付且未迁移的用户）：Pro 每月 300 次 premium requests，Pro+ 每月 1,500 次，超出部分 $0.04/次；从 2026-06-01 起代码审查倍率为 13【官方，docs legacy】。
- 已验证的教师和热门开源维护者可能免费获得 Pro【官方】。

### 2.2 组织/企业档

| 档位 | 月费/席位 | 含 credits/用户/月 | 要点 | 来源 |
|---|---|---|---|---|
| **Copilot Business** | **$19** | 1,900（组织内共享池） | 集中管理和策略 | 【官方】docs |
| **Copilot Enterprise** | **$39** | 3,900（共享池） | 新模型优先；需要 GitHub Enterprise Cloud | 【官方】docs |
| **Copilot access（2026-10-28 起，销售渠道）** | **GHEC 授权用户 $0；Copilot Standalone $10/用户/月** | **不含 credits，从第一次使用就按量计费** | 功能和模型与 Copilot Enterprise 相同；同一企业只能选“含 credits 席位”或“access”其中一种模式；自助开通会分批开放 | 【官方】docs、Community #211016、Universe 2026 |

- 迁移期优惠：2026 年 6–8 月，现有 Business 客户每月 $30 credits，Enterprise 客户每月 $70 credits【官方】。
- 超出共享池的部分按 $0.01/credit 计费。管理员可以在企业、成本中心、用户三级设预算【官方】。
- 采购顾问 Redress 指出，过去“$39 Copilot Enterprise + $21 GHEC ≈ $60/人”才是真实成本；新的 access 模式把席位费归零，改为纯按量计费【媒体/顾问】。
- Copilot 暂不支持 GitHub Enterprise Server【官方】。

### 2.3 计费模式变化总结（重要）

| 时间 | 模式 |
|---|---|
| 2022–2025-06 | 纯席位订阅（个人 $10/$19，Business $19，Enterprise $39） |
| 2025-06-18 起 | 席位 + premium requests 月度配额，超出 $0.04/次 |
| **2026-06-01 起** | **席位 + 内含 AI Credits（按 token 计价，以各模型公开 API 价格为准），超出部分按量付费** |
| **2026-10-28 起（企业可选）** | **GHEC 席位内含 Copilot 使用权，AI 全部按量计费（类似云服务）** |

## 4. 安全（GitHub Advanced Security，2025-04 拆分）

## 6. 结论

1. **平台订阅价格多年未变**（Team $4、Enterprise $21）。增量收入主要来自 **Copilot、Actions/Codespaces 按量计费和安全模块**。
2. **2026 年是 Copilot 定价体系的分水岭**：从“包月不限量”转为“按 token 消耗计费”。企业侧进一步把 Copilot 席位费降到 0，把收入全部押在用量上，相当于 GitHub 的 AI 业务改成了云计算式的定价逻辑。
3. 社区对改价的反应偏负面（TechCrunch 2026-05-30 标题引用用户评论 “What a joke”）。微软财报口径则显示改价后消费收入明显上升（见 04）。
