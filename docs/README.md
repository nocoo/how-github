## 核心结论（15 条）

1. **归属与组织**：2018 年微软以 75 亿美元股票收购 GitHub。2025-08 CEO Dohmke 离任后，GitHub 并入微软 **CoreAI**（Jay Parikh），不再设独立 CEO（新 CEO 待核实）。【官方/媒体】
2. **规模**：开发者 **2.25 亿+**（2026-09）；12 个月 push 179 亿次、commit 343 亿个、合并 PR 13 亿个；财富 500 强覆盖 90% 以上。【官方】
3. **代理化**：2026-09 有 **40% 以上的 PR 由 AI 代理起草**（3 月为 17%），单月 1.1 亿个；Copilot 月活用户中 55% 使用代理功能。【官方，Octoverse 2026】
4. **平台定价稳定**：Free $0、Team $4、Enterprise $21（每用户每月），多年未变；Enterprise 现在“包含 Copilot access”。【官方】
5. **Copilot 计费革命**：**2026-06-01 起全面按 token 计费（GitHub AI Credits，1 credit = $0.01）**。个人档 Pro $10、Pro+ $39、Max $100（每月总额度约 $15/$70/$200），Business $19、Enterprise $39（共享 credits 池）。【官方】
6. **企业新模式**：2026-10-28 推出 **Copilot access**：GHEC 授权用户席位费 $0，Standalone $10/人，AI 从第一次使用就按量计费，相当于把 Copilot 改成云服务式收费。【官方】
7. **按量产品**：Actions 以美元额度计费（Free $12、Team $18、Enterprise $300），Linux 2 核 $0.006/分钟；自托管 runner 收费计划已推迟；Codespaces 2 核 $0.18/小时。【官方】
8. **安全拆分**：Secret Protection **$19**、Code Security **$30**（每活跃提交者每月）；GHAS 收入**同比增长 50% 以上**（FY27 Q1）。【官方】
9. **公开财务**：唯一的美元口径是 **2024-07 的 20 亿美元年化营收（run-rate）**。之后只有增速表述：FY26 Q4 Copilot 营收环比加速 60% 以上；FY27 Q1 代理 credit 消耗翻倍，消耗 credits 的客户数环比增长 75% 以上。**利润从未披露。**【官方】
10. **毛利**：官方承认旧模式下 GitHub“吸收了大部分推理成本、不可持续”，CFO 称 Copilot 用量拖累了分部毛利率，改为按量计费后有所改善。【官方】
11. **竞争**：Cursor（据报 run-rate 约 40 亿美元，已被 SpaceX 以约 600 亿美元收购）、Claude Code（第三方追踪 ARR 超过 100 亿美元，低可信）、Codex（周活 2,000 万）抢占了“最强代理”的心智。GitHub 的应对是 Agent HQ 接入竞品、Fusion 多模型路由、MAI 自研模型降本。【媒体/官方】
12. **可靠性是最大短板**：Azure 迁移期间事故频发（2026-08 Actions 长时间故障被官方称为“不可接受”）；**OpenAI 被报道自研代码托管**；迁移预计 2027 年初完成。【官方/媒体】
13. **开源信任**：AI 垃圾 PR 推动 GitHub 推出“关闭 PR / 限制 PR 数”等功能；2026-04-24 起个人档数据默认用于训练；Gentoo 等项目迁往 Codeberg。【官方/社区/媒体】
14. **法律**：2026-09-16 第九巡回法院维持驳回 Doe v. GitHub 的 DMCA §1202(b) 诉求，认定 AI 输出是“新作品”，对 GitHub 有利；训练阶段的问题尚未裁决。【媒体/律所】
15. **总体判断**【推断】：托管本身在商品化，**“代理执行 + 审查 + 安全治理 + 用量计费”** 才是 GitHub 在 AI 时代的新护城河和收入引擎。短期看可靠性，长期看开发者信任。
