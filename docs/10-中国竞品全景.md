# 10 · 中国竞品全景

> 更新：2026-11-09（北京时间）｜ 第二期补充 ｜ 标注规则同 [README](README.md)，【X】= X 公开帖子。
> 结论先行【推断】：中国**没有一个能在开发者心智上替代 GitHub 的平台**。国产平台的真实优势在“合规/信创/私有化 + 网络可达 + 模型算力一体化”，而 GitHub 在中国的地位来自“全球分发 + 声誉 + 协作网络”。两者更像**分层共存**，而不是此消彼长。

【推断】三套数字差距巨大，原因是“注册账户”与“活跃贡献者”口径不同，以及大量中国开发者**不用真实 IP 登录**（@Goupenguin https://x.com/Goupenguin/status/1992476677285576895 ），国别归属本身就有误差。可以确定的是：**中国在 GitHub 上是前三的开发者来源国，但增速已落后印度和巴西**（第三方 Second Talent 称中国是前十中唯一自 2020 年以来未翻倍的国家，**待核实**）。

## 5. 竞争判断【推断】

1. **国产平台赢在“私有代码 + 政企”，GitHub 赢在“公开代码 + 全球分发”。** 中国 AI 公司（DeepSeek、Qwen、Kimi 等）要的是全球开发者的 star、issue 和下游集成，这只有 GitHub 能给；而企业内网代码、信创项目会继续流向 Gitee、云效、CodeArts、极狐。
2. **AI 资产层是国产平台最有机会的地方。** 魔搭 9 个月新增近千万用户、10 万模型，AtomGit 把免费算力和模型仓库打包——这与 GitHub 的强项错位竞争，对标的是 Hugging Face。英伟达收购 HF 后，如出现区域限制，魔搭/AtomGit 会直接受益（钛媒体观点【媒体】）。
3. **国产托管平台的口碑问题是结构性的**：审核制、Pages 下线、搬运争议、产品线反复（CODING 下线）都削弱了开发者信任。X 中文圈几乎找不到对 Gitee/GitCode 的高互动正面帖。
4. **风险在于外部冲击**：若美方对中国实施类似 2019 年伊朗式限制（目前无迹象），国产平台会被动获得大量迁移。2025-04 那次 19 小时的“误封”已经让部分人“紧急搬运项目回国”（@gefei55 https://x.com/gefei55/status/1911572433896915250 ）。
